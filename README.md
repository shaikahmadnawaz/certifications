# Certifications

Structured study notes and execution plans for cloud and platform certifications.

This repository is designed to be practical for learners and clean enough to grow into a long-term public knowledge base. Each certification track is organized into:

- `notes/` — concept learning, revision, and practice material
- `plan/` — day-by-day study plan and progress tracker

## Structure

- [aws/](./aws/) — AWS certification material
- Future folders can include `azure/`, `kubernetes/`, and others

## Start Here

1. Open [aws/cloud-practitioner/README.md](./aws/cloud-practitioner/README.md)
2. Follow the recommended study order there
3. Track daily progress in [aws/cloud-practitioner/plan/03-progress-tracker.md](./aws/cloud-practitioner/plan/03-progress-tracker.md)

This repo is structured so additional certification tracks can be added without changing the root layout.

## Conventions

- Certification content lives under `<provider>/<certification-name>/`
- `notes/` contains concept notes, flashcards, review sheets, and question banks
- `plan/` contains the study roadmap, daily timetable, and progress tracker
- Numbered files are ordered for guided study
