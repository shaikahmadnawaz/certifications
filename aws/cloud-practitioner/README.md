# AWS Cloud Practitioner Prep Pack

This folder is a focused study pack for the AWS foundational certification. It is written for beginners, but the notes also include the production context that helps concepts stick.

## How To Use This Folder

1. Start with [notes/01-cloud-fundamentals.md](./notes/01-cloud-fundamentals.md)
2. Finish [notes/02-core-services.md](./notes/02-core-services.md), [notes/03-security-compliance.md](./notes/03-security-compliance.md), and [notes/04-billing-support.md](./notes/04-billing-support.md)
3. Use [notes/05-practice-review.md](./notes/05-practice-review.md) every day for recall
4. Use [notes/06-exam-day-checklist.md](./notes/06-exam-day-checklist.md) during the final 48 hours

## Exam Strategy

- Learn service purpose before memorizing details.
- Focus on choosing the best AWS service for a scenario.
- Revisit IAM, pricing, S3, shared responsibility, and global infrastructure repeatedly.
- For wrong answers, write down why the wrong options are wrong. That is where most improvement comes from.
- Use [notes/07-official-objective-mapping.md](./notes/07-official-objective-mapping.md) to confirm you have covered every current official domain and task.
